1.ゲーム概要

タイトル：ぷかぷかタイピング
ジャンル：2Dタイピングゲーム
制作エンジン：Unity
プログラミング言語：C#
対応OS：Windows / MacOS / WEB
制作人数：1人

【ゲーム紹介】
『ぷかぷかタイピング』は問題に表示される言葉の読みをローマ字で入力するタイピングゲームです。
難易度を選択し、制限時間内にできるだけ正確に入力していきます。




2.あそびかた・操作方法

【ゲームの基本的な流れ】
1. タイトル画面で「はじめから」を選択します。
2.難易度を選択します。
3. 確認画面からゲームを開始します。
4.制限時間内に、表示された問題の読みをローマ字で入力します。
5.時間切れになると結果画面が表示されます。

【操作方法】
基本的にキーボードを使用します。
ポーズ：ESCキー
ゲーム開始：確認画面でSpaceキーまたはEnterキー
時間切れ後：SpaceキーまたはEnterキーで結果画面へ



3.ゲームシステム

【難易度】
かんたん：制限時間60秒
ふつう：制限時間90秒
むずかしい：制限時間120秒

【結果】
正解タイプ数：正しく入力したキーの数
ミスタイプ数：間違えて入力したキーの数
合計入力数：正解タイプ数とミスタイプ数の合計
平均入力速度：正解キー数を実際のプレイ時間で割った値（回/秒）
※ポーズ中の時間はプレイ時間に含まれません。

【設定】
設定画面では、次の項目を切り替えられます。
・ローマ字表示
・ふりがな表示
・BGM
・タイピング音
・正解音
・ミス音



4.動作環境・起動方法

【対応OSについて】
WindowsとMacOS、Web版となります。

【起動方法について】
1.配布してあるゲームフォルダを展開します。
2.フォルダ内のゲーム実行ファイル（Windowsの場合はexeファイル、MacOSの場合はappファイル）を起動します。
3.タイトル画面からゲームを開始します。



5.制作環境・技術

【開発環境について】
ゲームエンジン：Unity6.6
プログラミング言語：C#
背景描画ツール：ibisPaint
